📩 SMS Spam Detection using NLP

Welcome to this project where we explore Natural Language Processing (NLP) techniques to classify SMS messages as Spam or Non-Spam. This notebook uses basic text preprocessing and the Naive Bayes algorithm to build a simple yet effective spam classifier.

🧠 About the Project

This project explores:

- Real-world SMS message dataset (SMS_test.csv)
- Text preprocessing: cleaning, stemming, and stopword removal
- Creating a Bag-of-Words model using CountVectorizer
- Splitting data into training and testing sets
- Training a Naive Bayes (GaussianNB) classifier
- Evaluating performance with accuracy and confusion matrix
- Predicting unseen SMS messages

🛠 Technologies Used

- Python
- Pandas, NumPy, Matplotlib
- NLTK for NLP processing
- Scikit-learn for machine learning
